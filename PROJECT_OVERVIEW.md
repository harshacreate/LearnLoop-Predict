# LearnLoop-Predict — Student Support Research Prototype

A synthetic course-term exercise using attendance, assessment performance, prior GPA, study time, LMS activity, late submissions, employment, and aid status.

Synthetic data only. Research/education only. This is not a dropout decision system. Educational support requires contextual human review, student consent, and careful assessment of subgroup effects. The working-status diagnostic is descriptive.

Run: `python -m learnloop.train --json`; tests: `python -m pytest -q`.
